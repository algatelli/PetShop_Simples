# PetShop_Simples
Projeto para a disciplina de Fundamentos de Sistemas WEB - PUCRS - 2026
Ajuda do PetShop Simples
Se você tiver alguma dúvida ou precisar de assistência, entre em contato conosco através do e-mail: algatelli@gmail.com

Esse é um site de exemplo desenvolvido por Alexandre Gatelli para fins educacionais. Ele não representa um negócio real e não realiza vendas de produtos ou serviços.
Há apenas uma simulação de um site de PetShop, com informações fictícias sobre produtos e serviços.
Para mais informações, consulte a página inicial do site.

Este site foi desenvolvido com o objetivo de demonstrar conceitos de desenvolvimento web, incluindo HTML. Ele serve como um recurso educacional para estudantes e entusiastas da área de tecnologia.

Se você tiver alguma sugestão ou feedback sobre o site, sinta-se à vontade para nos contatar.

No cabeçalho há um título e alguns links para as diferentes categorias de produtos.
No corpo da página, há seções dedicadas a cada categoria de produto, com descrições e imagens.
No rodapé há informações de contato e links para políticas de privacidade e termos de uso.

Este site é apenas um exemplo e não realiza transações comerciais reais. Qualquer semelhança com produtos ou serviços reais é mera coincidência.
